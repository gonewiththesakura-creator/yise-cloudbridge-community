壹色云桥 Windows 客户端 2.6.0

系统要求：Windows 10/11 x64。

使用方法：
1. 将整个文件夹解压到本机，不要只复制“壹色云桥.exe”。
2. 向管理员确认 HTTPS 服务地址。设置 CLOUDBRIDGE_API_BASE_URL 环境变量，或在 %LOCALAPPDATA%\CloudBridge\settings.json 填写 {"apiBaseUrl":"https://管理员确认的主机名:端口/"}。环境变量优先；错误配置不会回退到其他服务器。
   服务地址只能包含 HTTPS 主机名与可选端口，不得包含账号密码、路径、查询参数或片段。配置后重新启动客户端。
   未配置或配置无效时，客户端会说明原因并退出，不会检查更新、注册设备或连接服务器。
   仅使用你信任且由管理员确认的服务。激活与续期会向该服务发送激活码、设备名称、指纹哈希及设备公钥/签名。
3. 运行“壹色云桥.exe”。
4. 首次运行时输入管理员发放的一次性激活码。
5. 在 VLESS 与 TUIC 线路之间手动选择，或使用“智能测速”获取推荐线路。
6. 默认“绕过大陆”会让大陆网站直连；“全局 TUN”会接管全部应用流量，并在连接时请求管理员权限。
7. 点击“连接”，客户端会通过设备授权的短期证书建立专线。
8. “流量”页面可查看实时上下行曲线、本机会话、今日流量和套餐累计。

自动更新：
- 服务地址有效时，客户端启动后会向所配置的服务检查发布策略。
- 强制更新会先校验文件大小与 SHA-256，再自动替换程序并重启。
- 设备绑定保存在 Windows 用户目录，更新不会要求重新激活。
- 断开、退出或异常重启客户端时，原有 Windows 系统代理会自动恢复。
- 点击窗口关闭按钮只会收起到系统托盘；请在托盘菜单选择“退出”正式关闭。

设备保护：
- 客户端优先创建不可导出的 TPM 硬件密钥。
- 原始 BIOS、主板和 CPU 信息不会上传，只上传组合指纹的 SHA-256 哈希。
- VLESS 使用本机不可导出的设备私钥；TUIC 使用经该设备签名授权、只保存在本机 Windows 密钥库中的传输私钥。
- 运行配置和短期传输私钥只在代理核心启动时短暂写入，加载后立即删除；复制客户端文件或配置到另一台电脑无法连接。
- 更换电脑前，请让管理员在后台执行“解绑设备”，再生成新的激活码。

注意：
- 本客户端当前未购买商业代码签名证书。Windows 首次运行可能显示发布者未知提示。
- 不要共享激活码。激活码仅可使用一次，并会在 30 分钟后过期。
- 不要删除 core 文件夹或其中的 sing-box.exe、geosite-cn.srs、geoip-cn.srs。
